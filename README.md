# Conreate Remote Apps

Home Assistant App repository for Conreate Cloud remote access.

Install this repository in Home Assistant using:

```text
https://github.com/yymonday/conreate-remote-apps
```

The App requires the published HA App image in GitHub Container Registry. The Agent Core is a private build input and is bundled into that App image; customers do not need access to the Agent image. See `conreate_remote/DOCS.md` for activation, recovery, and troubleshooting. The server-side Control Plane and Agent Core source are maintained in the private [Conreate Cloud repository](https://github.com/yymonday/conreate-cloud).
