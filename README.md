# Conreate Remote Apps

Home Assistant App repository for Conreate Cloud remote access.

Install this repository in Home Assistant using:

```text
https://github.com/yymonday/conreate-remote-apps
```

The App requires a published, version-matched Agent Core and HA App image in GitHub Container Registry. See `conreate_remote/DOCS.md` for activation, recovery, and troubleshooting. The server-side Control Plane and Agent Core source are maintained in the private [Conreate Cloud repository](https://github.com/yymonday/conreate-cloud).
